# Rate Anything Community

Rate Anything Community is an entertainment-focused community in which members define how arbitrary tangible or abstract things should be rated, publish ratings, reuse one another's rating schemes, and discuss the results.

## Language

**Thing**:
Any tangible object, product, experience, idea, or abstract concept that a member chooses as a subject for rating.
_Avoid_: Product, item, object

**Rating Scheme**:
A reusable scoring structure created for one Thing and made up of one or more Criteria.
_Avoid_: Template, rating flow, tag set

**Criterion**:
A named dimension within a Rating Scheme on which a member assigns a score.
_Avoid_: Tag, label, category

**Rating Submission**:
One member's completed set of Criterion scores using one Rating Scheme, together with any optional written review or images.
_Avoid_: Rating, review, scorecard

**Result Score**:
The calculated numeric outcome of one Rating Submission. It expresses entertainment-oriented opinion rather than verified fact.
_Avoid_: Official score, true score

**Comment**:
A discussion response attached to a Rating Submission.
_Avoid_: Review, reply

**Member**:
A registered user who may create Things, create Rating Schemes, submit ratings, and participate in discussion.
_Avoid_: Customer, author, rater

**Moderator**:
A privileged Member who may remove unlawful, violent, sexual, or otherwise prohibited community content.
_Avoid_: Django admin, site owner

**Media Asset**:
An image contributed as part of a Rating Submission and displayed in the relevant Thing's community content.
_Avoid_: Attachment, product image

**Content Report**:
A Member's request for a Moderator to review potentially prohibited community content.
_Avoid_: Complaint, flag
